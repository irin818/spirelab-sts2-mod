# 魔女美术资源包

V1.6 的角色设定以 [规格书](../SpireLab_The_Witch_GDD_v1.6.md) 和 [角色母版](../docs/art/witch-v2/source/character-bible.png) 为准。魔女身形娇小纤细，黑色中长卷发带少量暗红挑染，深红眼睛，宽檐尖顶帽配白蕾丝，哥特宫廷裙装以黑与象牙白为主。古典裂镜中的人格沿用同一轮廓和服装，用更兴奋、危险的笑容区分。采用精致日式赛璐璐动漫、高反差光影和清晰剪影。

用复古哥特插画的构图、清晰的赛璐璐色块和柔和的紫灰色偏。胶片颗粒应细而轻，在游戏缩略尺寸仍看得清五官、手势与轮廓。每张图使用单独构图和简洁背景，主体放在中央安全区，边缘避免拼版线、卡框、文字和其他格子的残片。交付前用 150 像素宽预览，逐张比较清晰度和主体差异。透明人物要在深浅两种背景下检查发梢、帽檐和脚边。

四种牌面主题沿用共同结构，用图案和局部色彩区分。魔药用暗酒红与黄铜金、药瓶和火焰。镜子用银蓝与冷白、裂镜和晶体。魔法书用幽紫与羊皮纸、书页和咒文。欲望用猩红与黑、荆棘和契约。稀有度由运行时卡框表示。插画本身留给构图和动作，费用、牌名、关键词与数值由游戏绘制。

## 资源包结构

把 ZIP 解压后的文件按表放在 artwork/source/ 下。包根目录可直接包含 cards/、powers/ 等目录。用 [manifest.csv](manifest.csv) 的 source_path 和稳定 ID 对齐。卡图直接用 B01.png、C01.png、R10.png 一类编号。

| 目录 | 建议原图 | 导入结果 |
| --- | --- | --- |
| cards/ | 普通 1000×760，古代 1212×1704，PNG | 普通 500×380，古代 606×852。按中心裁切。双眼、手势与主题物件留在中央 80%，并以约 150 像素宽检查缩略图 |
| character/ | 选角 1600×900，肖像方图至少 256×256，战斗与镜像使用透明 PNG | 选角 1600×900，左侧留给角色信息。肖像 128×128，自动生成锁定灰图。战斗 391×438，镜像 238×438，底边对齐 |
| powers/ | 每项一张 512×512 透明 PNG，12% 边缘留白 | 64×64 状态角标与 256×256 大图。均由同一原图生成。角标需要在游戏内约 30–40 像素范围内能辨认 |
| relics/ | 512×512 透明 PNG | 94×94 本体与描边、256×256 大图。一张原图生成三份 |
| potions/ | 512×512 透明 PNG | 256×256 本体与描边 |
| frames/、ui/、vfx/ | 使用清单要求的 SVG 宽高与 viewBox | 体系徽记、界面标记、战斗反馈图。Godot 场景继续维护动画、脚点、镜像切换和原生面板布局 |

未提供新文件时，使用工程随附的资源。状态目录中的线稿 SVG 是临时反馈图标。提供对应 PNG 即可同时替换小图和大图。卡框着色使用现有着色器，资源包可以换四类徽记。新动画骨骼或改变场景节点层级需要单独的场景集成。

来源和授权应随 ZIP 附上。按稳定 ID 记录创作者或生成工具、原始文件名和允许的使用范围。将正式交付图与占位素材区分，在仓库记录对应行的授权和状态。现有历史原图保留在 docs/art/witch-v2/source/。

以工程清单的 `game_object_id` 和 `target_path` 为准。外部包自带清单用于核对，接收时先把外部 ID 映射到已注册对象，再复制验收图到 `source_path`。`current_status` 记录使用状态，`quality_status` 记录图像等级，`source_information` 记录来源路径与原图哈希，`license` 记录使用范围。[V1.6 外部包逐项审查](../docs/art/witch-v1.6-source-audit.csv)

## 安全替换

    ./scripts/dev-macos.sh art-sync --dry-run
    ./scripts/dev-macos.sh art-sync
    ./scripts/dev-macos.sh art-sync --source "/path/to/unpacked/artwork/source"

依赖 macOS 的 sips、Python 3、FFmpeg 和已配置的 MegaDot。先检查源图、透明像素、尺寸与目标路径，再成批导出。成功时自动重新导入并构建 PCK。校验或打包失败时保留原有图与包。转换只写入运行资源及本地生成目录，源图可以独立归档。增量记录和预览留在 generated/、previews/。测试新图可先给 --source 一个单独目录，并用隔离游戏副本验证。

导入后运行 `./scripts/smoke-macos.sh witch-art`。在原生选角、手牌、血条下角标与悬停说明中观察清晰度和布局。日志会给出截图目录。整包导入前先做质量比对，只有确认清晰且语义正确的素材才进入 `artwork/source/`。游戏用的旧纹理和未采用新原图各自保留历史或外部快照。
