# 血色终镜 V3 · 镜后魔女

V3 使用用户最后交付的 1672×941 低机位插画制作透明上半身，以灵魂镜的居中遮挡建立前后关系。原版致死和胜利钩子负责演出的起点与结算。《狂赌之渊》的生命返还先于胜利演出，随后按原版流程生成奖励。

| 时间 | 镜头与表演 |
| --- | --- |
| 0.00–0.42 秒 | 从真实敌人受击框推进，逐渐减速并轻微收稳，镜裂沿目标实际位置展开。 |
| 0.42–1.05 秒 | 真实战场向后拉远，银紫镜缝向两侧展开。背景移动幅度小于敌人所在的战斗层。 |
| 1.05–1.70 秒 | 主镜占据前景，镜中灵魂先清晰。镜头沿向上偏右的二次曲线爬升，逐渐让镜后的魔女聚焦。 |
| 1.70–2.20 秒 | 短幅弧线缓慢推进面部。抬眼、微眯、抬眉、偏头和单侧嘴角各自起动，最后成形的是微笑。 |
| 2.20–2.75 秒 | 镜头后拉，袖和手反向伸至镜框前。画面焦点移到掌心与镜核。灵魂和裂纹先收束，音轨在冲击前退去。 |
| 2.75–2.93 秒 | 同一时间点握拳、碎镜、播放冲击音。镜核短促推进，银色镜片随回弹飞向前景。 |
| 2.93–3.55 秒 | 手掌回落，镜片退散，面部重新虚化，镜层回到原位，原版战场与奖励接续。 |

## 运镜和景深

- 现有战斗路径通过目标版本的 `NCombatRoom.SceneContainer` 和背景容器完成，取景读取致死前的受击框。`NCombatUi` 是同级独立节点。原镜头的位置与缩放在入镜、房间释放和中断时恢复。继续使用现有单人模式守卫。
- 自建镜界使用独立的镜廊、半身、主镜、手掌和碎片层。镜头位置、倍率和旋转按不同的深度权重分配，法术线从手掌和镜核在各自图层投影后的坐标连起来。
- 镜廊、镜框、半身和发束的景深通过各自绘画纹理的 mip 层级采样实现。移动焦点只改变局部素材的采样层和空间权重。
- 代码入口位于 `CrimsonFinalMirror.cs`，镜头路径见 `CrimsonMirrorCamera.cs`。角色局部动作由 `CrimsonMirrorPortrait.cs` 驱动，半身、手势及 Shader 位于 `finisher/v3/`。

## V3 素材

- 新半身保留 1672×941 的原始裁幅和透明通道，前后发束从同一幅图以羽化蒙版分出。另有一张直接取自用户原图的 435×307 表情纹理，使用独立眼、眉、口遮罩与局部对位。眼睑、视线和嘴角的过渡包含小幅纹理形变，头和肩的运动保留原画轮廓。
- 手部和衣袖采用黑绒、象牙蕾丝与银饰。四张 631×623 透明关键帧分别是前伸、张掌、收指、握拳。前两段做短促重叠，握拳在碎镜点切入。镜廊、主镜、切片纹理与冲击音沿用已有正式绘画资产。
- 新音轨 `finisher/v3/ritual.wav` 在揭幕后进入玻璃泛音，在收束段加强低频，在撞击前收低音量。与原有 `mirror-shatter.wav` 共用主时钟。
- 原图、透明编辑图与袖手拼图位于本机 `.local/crimson-v3/source/`。以最后提供的 `user-portrait.png` 为主参考。半身编辑移除背景、外镜框和前景手，保留角色头部角度、玫瑰帽饰、红宝石与蕾丝。按原图手势方向制作四张袖手，正式对焦阶段以全分辨率采样，边缘只去除近透明的底边残影。已有通用灵魂是无法取到敌人安定静态纹理时的回退。细化空间包括更纯净的发束遮挡底图、眼睑和指节中间帧，及为常见 Spine 敌人匹配更具体的剪影。

## 本地重跑

在 Finder 双击根目录 `启动魔女本地测试.command`，选择魔女并正常打完一场战斗。脚本使用固定的 `.local/witch-local-play/SlayTheSpire2.app`、离线运行和独立 App Support 测试目录。启动器使用游戏自带的开发窗口选项，避免已保存全屏偏好下的黑屏。编译和运行日志在 `.local/witch-local-play/logs/`。

```bash
./scripts/smoke-macos.sh witch-finisher
SPIRELAB_SMOKE_RESOLUTION=1600x900 SPIRELAB_SMOKE_TIMING_ONLY=1 ./scripts/smoke-macos.sh witch-finisher
```

脚本会打印本次 PNG 和日志目录。截图从多场真实战斗分别采集，性能复跑关闭截图读取。
