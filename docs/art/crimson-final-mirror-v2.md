# 血色终镜 V2

V2 继承 [V1 的胜利钩子与镜界](crimson-final-mirror.md)。以下为当前分镜，V1 笔记保留作历史参照。

| 秒 | 镜头 | 实现 |
| --- | --- | --- |
| 0.00–0.45 | 敌人特写 | 死亡钩子保存受击框的归一化位置和尺寸。镜头向敌人上半区域推进，裂纹跟随被投影的位置。 |
| 0.45–0.90 | 转向魔女 | 五次缓动在两段焦点间移动，原版战场背景与主体按不同幅度跟随。猩红丝线与中央镜幕衔接。 |
| 0.90–1.50 | 魔女特写 | 高精度上半身、前后发束、眼光、肩袖、抬臂和张掌。全身魔女留在前景。镜界远景按更低比例移动。 |
| 1.50–1.95 | 坍缩 | 镜头由脸与手掌移到灵魂镜。手指收紧，裂纹和魔力丝向中心压缩。 |
| 1.95–2.18 | 爆裂 | 握拳与主镜消失、银镜片飞散和冲击音效由同一时间点触发。镜界有短促回弹。 |
| 2.18–2.70 | 回到现实 | 特写、碎片、镜廊和法阵消散，恢复原版战场和奖励。 |

## 节点和素材

- `CrimsonMirrorCamera.cs` 只暂借原版 `NCombatRoom.SceneContainer` 与独立的 `BgContainer` 来做开场控制。原版 `NCombatUi` 是分离的节点。镜界由 `CanvasLayer` 下的 `StageShot` 接管，HUD 沿用原版坐标。原镜头位置与缩放在开场淡出和房间退出时恢复。
- `CrimsonMirrorPortrait.cs` 使用 `finisher/v2/` 的独立 1024×1536 透明特写、前后发束与四张 768×512 袖手姿态。发束独立位移，头部和肩袖在纹理坐标内小幅摆动，眼光使用同一坐标附着。掌心位置取实际手势锚点。它与 V1 保留的全身前景魔女使用不同的素材和运动速度。
- 原始生成图保存在本机 `.local/crimson-v2/source/`。以内建图像生成器读取 `docs/art/witch-v2/source/character-bible.png`。特写提示聚焦同角色的完整帽檐、黑色卷发、红眼、黑白哥特袖衣、紫红逆光与透明轮廓。手势提示要求相同袖口和锚点的抬手、张掌、收指和握拳四格。运行素材从原始图按 Alpha 对齐、分层和裁切。
- V2 特写和手势是本版运行美术。头发分层通过原画蒙版获取，袖手是独立关键帧，肩袖和头部的连续动作采用轻微形变。若进一步追求逐帧表现，可补画发束遮挡后的底图和手指中间帧。Spine 死亡残影消失时使用通用灵魂，其镜头仍取实际敌人位置。
- 复用 V1 哥特镜廊、银镜、碎片、落幕和音轨。银月保留在工程历史素材中，V2 演出使用上半身特写。首场发牌前，用很小的画布绘制预热三个 Shader 的管线。

## 手动试玩与回归

在 Finder 双击项目根目录的 `启动魔女本地测试.command`。启动器会检查项目依赖、重新编译和打包，把当前 Mod 与 BaseLib 装入 `.local/witch-local-play/SlayTheSpire2.app`，随后进入真实游戏主菜单。该副本关闭 Steam 集成，正常游戏可一直玩到主动退出。

每个项目路径对应独立的 `~/Library/Application Support/SpireLabLocal-…` 存档与设置。启动器复用同一副本和测试档，更新游戏版本时才替换副本。`.local/witch-local-play/logs/` 保留最近两次构建、打包、启动与错误记录。

自动回归独立运行。退出手动游戏窗口后，在项目根目录执行：

```bash
./scripts/smoke-macos.sh witch-finisher
SPIRELAB_SMOKE_RESOLUTION=1600x900 SPIRELAB_SMOKE_TIMING_ONLY=1 ./scripts/smoke-macos.sh witch-finisher
```

脚本打印截图和日志位置。第二条命令关闭截图读回，用于观察首播与重播的帧时间。

本机窗口回归覆盖普通攻击、反伤、AOE、双段攻击、毒伤中断、Boss、战败与奖励。截图模式通过 111 项断言并保存 9 张实机 PNG。不同章节的关键帧分散采自多场战斗，减少 GPU 读回对下一镜头的影响。Finder 双击两次均启动游戏，游戏日志确认复用同一个测试用户目录，App 副本文件编号一致。
